The whole internet, in exactly one word:

**doomscroll**

One word, nothing else. The endless feed you cannot stop scrolling —
news, memes, arguments, videos, shopping — all running on the same
loop: one more scroll, while promising you are almost informed, almost
entertained, almost done.

## Entry

`main.ts` writes the word to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (default `/output`) and self-checks that the
entry is exactly one word: lowercase letters only, no whitespace,
no extra text.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
